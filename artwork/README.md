# ComicViewer launcher artwork

`comicviewer-launcher-icon-512.png` is the canonical square artwork for store listings, release
pages, and other ComicViewer distribution material.

Android's density-specific legacy launcher icons and API 26 adaptive icon are derived from the same
design. The adaptive foreground keeps the comic page and yellow bookmark inside Android's mask-safe
area over the design's navy background.

The artwork was created specifically for ComicViewer and is distributed under the repository's MIT
License. No stock, trademarked, or externally licensed visual asset is incorporated.
